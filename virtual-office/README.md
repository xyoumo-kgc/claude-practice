# バーチャルオフィス（Claude エージェント編成・リアルタイム版）

ピクセルアート調のバーチャルオフィスです。**手元の Claude Code が今なにをしているか**が、
社員（メイン＋サブエージェント）の動きとしてリアルタイムに映ります。

| オフィスの表示 | 実際に起きていること |
| --- | --- |
| Claude の席が緑ランプ・タイピング中 | Claude Code が作業中（「いま」に読んでいるファイルや実行中のコマンド） |
| Claude の席に赤い「!」 | **あなたの許可待ち**（ツールの実行確認など） |
| Plan / Explore などが出社して作業 | サブエージェントに仕事を依頼中（中で使っているツールも表示） |
| 知らない名前の「新入社員」 | 自作のサブエージェントが初めて呼ばれた（自動で席を用意） |
| 3分手が空くと休憩室へ | ハンモック・ブランコ・コーヒー前などで休憩 |
| 案件ボードの付箋 | Claude が作った TODO リスト（作業中／済 が自動で切り替わる） |
| NEWS ・活動ログ | 指示・出動・完了・確認待ちなどの出来事 |
| リソースモニター | Claude Code の使用量（ccusage で5分おきに自動集計） |

## しくみ

```
Claude Code ──(フック)──▶ office-hook.mjs ──▶ server.mjs ──(SSE)──▶ ブラウザの office.html
                                              ▲
                              ccusage（使用量・5分おき）
```

- **server.mjs** … 依存パッケージなしの小さなローカルサーバー（`http://127.0.0.1:4649`）。
  自分のPCの中だけで待ち受け、外からはつながりません。
- **office-hook.mjs** … Claude Code のフックから呼ばれ、出来事をサーバーへ送るだけの軽いスクリプト。
  サーバーが止まっていても何もせず即終了するので、Claude Code の動作を邪魔しません。
  ファイルの中身などは送らず、表示に必要な項目（ファイル名・コマンド名など）だけを送ります。
- **install.mjs** … `~/.claude/settings.json` にフックを登録（他の設定・フックはそのまま。バックアップも作成）。

> **前提**: Node.js 18 以上／Claude Code をこのPC上で使っていること（CLI・VS Code 拡張・デスクトップアプリのローカル実行）。
> claude.ai 上のクラウド実行のセッションは、あなたのPCとつながっていないので映りません。

## セットアップ（Windows）: `setup.bat` をダブルクリック

以下を全部自動でやります:

1. Node.js の確認
2. Claude Code にフックを登録
3. サーバーを起動してブラウザで開く（**ログオン時の自動起動**もスタートアップに登録）
4. （聞かれて y と答えたら）毎朝7時にオフィスを開く

最後に、**いま開いている Claude Code を一度終了して起動し直してください**（フックは起動時に読み込まれます）。
ブラウザ上部に「LIVE 接続中」と出ていれば成功です。

| ファイル | 用途 |
| --- | --- |
| `setup.bat` | 最初に1回。全部入りのセットアップ |
| `start.bat` | サーバーを起動してオフィスを開く（起動済みなら開くだけ） |
| `uninstall.bat` | フック・自動起動・タスクを外してサーバーを停止 |
| `update-usage.bat` | （サーバーを使わない場合用）`usage.js` だけを更新して、ファイル直開きでもゲージを出す |

Mac / Linux の場合は `node install.mjs` → `node server.mjs` → `http://127.0.0.1:4649` を開く、で同じように動きます。

## うまく映らないとき

- **「オフライン（サンプル表示）」のまま** … `office.html` をファイルとして直接開いています。`start.bat` から開くか、`http://127.0.0.1:4649` を開いてください。
- **「再接続中…」** … サーバーが止まっています。`start.bat` を実行。
- **社員が動かない** … Claude Code を起動し直したか確認。Claude Code の `/hooks` で `office-hook.mjs` が登録されているか確認できます。
- **使用量が「取得エラー」** … `server.err.log` を確認。ccusage（コミュニティ製）の出力形式が変わった可能性があります。
- **ポートを変えたい** … 環境変数 `VIRTUAL_OFFICE_PORT` をサーバーとフックの両方に設定。

## 週ゲージを%表示にする

プランの週上限（トークン数）は公開されていないため、初期状態では週はトークン数表示です。
上限に当たった週の合計トークン数が分かったら、`update-usage.mjs` 先頭の
`WEEKLY_TOKEN_LIMIT` にその数値を入れると %ゲージになります。
5時間ゲージは「過去の5時間枠で一番多く使った量」を上限の目安にした推定値です（公式の `/usage` とは多少ズレます）。

## カスタマイズ

- 社員の名前・役割・色・部屋 … `server.mjs` の `ROSTER`
- 社長のやりたいことリスト・顧問室 … `office.html` の `BOSS_TODO` / `ADVISORS`
- 休憩に入るまでの時間など … `server.mjs` 先頭の定数（`IDLE_TO_REST` など）
- `office.html` の `EMP` / `NOTES` / `NEWS` は、サーバーなしで開いた時のサンプル表示用です

## 保存されるデータ

`state.json`（「きょうの完了」・案件ボード・活動ログ）と `*.log` がこのフォルダに作られます。
どちらも Git の管理対象外です。指示の文面は先頭の数十文字だけ、ローカルにのみ保存されます。
