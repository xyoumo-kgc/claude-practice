# 床コーティング施工写真の加工

施工写真4枚を、Web・SNS掲載向けに仕上げたもの。

```
original/   撮影データ（無加工）
edited/     加工後の納品データ
compare/    ビフォー/アフター比較シート
enhance.py  加工パイプライン
compare.py  比較シート生成
```

## 加工方針

階調・露出の処理はすべてリニア空間で行い、色相のずれを防いでいる。
写真ごとに課題が違うため、`enhance.py` の `JOBS` で個別にパラメータを指定している。

| 写真 | 元の課題 | 加工内容 |
|---|---|---|
| photo1 | 白っぽく眠い、木目のツヤが出ていない | コントラストと明瞭度を上げ、やや暖色寄りに。木目と艶を強調 |
| photo2 | 露出不足、緑カブリが全体を覆う | 露出とシャドウを持ち上げ、壁・天井の緑カブリを軽減。UVランプの緑光は残す |
| photo3 | 同上（photo2 より明るめ） | 同方針。床材と階段の木色を復元 |
| photo4 | 逆光でカスミがかかり全体が白飛び気味 | 明瞭度を強めにかけてカスミを除去、ハイライトを抑えて艶の反射を残す |

緑光の2枚はグレーワールドのホワイトバランスをそのまま当てると緑の光そのものが
消えて絵の主題が失われるため、`wb_clip` でゲインの上限を絞り、
壁面のカブリだけを取って光源の緑は残している。

## 再実行

```sh
pip install pillow numpy
cd photos
python3 enhance.py   # edited/ を生成
python3 compare.py   # compare/ を生成
```
