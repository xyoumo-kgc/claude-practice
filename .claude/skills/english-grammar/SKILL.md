# /english-grammar — 文法を会話でつかむ

## 役割

学習者が聞いた文法項目を、`english-learning/curriculum/03-grammar-simplified.md` と同じ形式で説明する。
**抽象的な用語の羅列ではなく、会話例から入る**。

## 出力形式（固定）

1. **一言ルール**（1〜2 文。専門用語は最小限、使うなら日本語で言い換える）
2. **会話例**（A/B の 4〜6 行。学習者の生活に近い場面。対象の文法が 3 回以上登場）
3. **どう機能しているか**（会話例の該当箇所を引用して、「ここで〜だから〜の形」と 2〜3 点）
4. **日本語話者がつまずく点**（× の例 → ○ の例、1〜3 組）
5. **自分で 3 文**（学習者に作らせる空欄。ヒントとして場面を指定）
6. **似ている項目との違い**（該当があれば 1 つだけ。例: 過去形 vs 現在完了）

## 手順

1. 引数（項目名）がなければ、`english-learning/progress/status.md` のフェーズと `progress/vocab-log.md` の「文法」種別の既習項目を見て、計画文書（`01-learning-plan.md` フェーズ 4 の学習順）の **次の未習項目** を提案する。
2. `03-grammar-simplified.md` に該当項目があればそれを土台に、学習者の状況（既習語彙・興味）に合わせて会話例を **新しく作る**（丸写しはしない）。
3. 学習者が 3 文を送ってきたら添削し、誤りを `progress/mistakes-log.md` に追記する（分類はルール名）。
4. ルールをログに登録する:

   ```bash
   python english-learning/scripts/due.py add 文法 "現在完了（経験）" "have + 過去分詞。いつかを言うなら過去形" "Have you ever been to Okinawa?" grammar
   ```

## 注意

- 「もっと簡単に」と言われたら、会話例を短くし、用語をゼロにして言い直す。
- 例外や細則は聞かれるまで出さない。まず 8 割通じる原則だけ。
- 出力は日本語、例文は英語。
