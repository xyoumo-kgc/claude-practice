# /english-review — 間隔反復レビュー

## 役割

学んだことを定着させるためのクイックテスト（**5〜10 分**）を作り、結果をログに反映し、弱点を特定する。

## 手順

1. リポジトリルートで復習対象を取得する:

   ```bash
   python english-learning/scripts/due.py list --new 5
   ```

   - 「復習期限の項目」（古い項目、Box の小さい順）と「最近学んだ項目」（新しい項目）が出る
   - 期限項目が 0 件なら、Box の低い順に 5 件 + 最近の 5 件で出題する
   - ログが空なら、まず `/english-lesson` を案内して終了する
2. `english-learning/progress/mistakes-log.md` を `python english-learning/scripts/due.py stats` で集計し、**多い分類の項目を優先的に混ぜる**。
3. 出題（**合計 10〜12 問**。古い項目 6〜7 割、新しい項目 3〜4 割）
   - **A. 穴埋め**（4〜5 問）: 例文の対象語を空欄にした短いフレーズ。ヒントとして日本語訳を添える
   - **B. 日本語 → 英語**（3〜4 問）: 対象語を使う 1 文
   - **C. 英語 → 日本語**（2〜3 問）: 対象語を含む 1 文
   - 各問に `[ID]` を付けて、どのログ項目かを追跡できるようにする
   - 解答は出さない。学習者の回答を待つ
4. **採点**（学習者の回答を受けてから）
   - 問ごとに ○/× と正解、× には 1 行の理由
   - 表記ゆれ・同義の言い換えは ○ にする（意味と文法が正しければ可）
5. ログ更新:

   ```bash
   python english-learning/scripts/due.py grade 12 ok 7 ng 15 ok ...
   ```

   × の項目は `mistakes-log.md` にも追記する（出典 `review`）。`lesson-log.md` に 1 行。
6. **最も間違えやすい箇所の報告**（固定形式）
   - 今日の × を分類別に集計 + `stats` の累計を合わせて、**上位 1〜2 分類** を挙げる
   - それぞれについて「なぜ間違えやすいか（1 文）」「次に集中する練習（`/english-grammar 〈項目〉` や `/english-correct` の指定範囲など具体的なコマンド）」
   - Box5 まで到達した項目があれば「定着」として褒める

## 注意

- 出題文は語彙ログの例文をそのまま使わず、**少し変えた文** にする（丸暗記ではなく使えるかを測る）。
- 学習者が途中で止めたら、回答済みの分だけ採点・更新する。
- 出力は日本語、問題文は英語。
