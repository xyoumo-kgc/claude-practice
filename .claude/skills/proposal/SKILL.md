# 提案書ワンストップ作成

ヒアリング内容から、**3D シーン → 提案書 PDF → 見積内訳** までを一度に用意するスキル。
このリポジトリの Web CAD（`src/`）と組み合わせて使う。

## 全体の流れ

```
ヒアリング（下の項目）
   ↓
要件スペック spec.json（mm 単位で記述）
   ↓  make_scene.py
シーン scene.json  →  Web CAD で「開く」→ 微調整 →「PDF出力」→ 提案書
   ↓  make_estimate.py
見積内訳 estimate.md / estimate.csv（下書き）
```

## ステップ 1: ヒアリング（不足があれば必ず聞く）

| 項目 | 例 | 必須 |
| --- | --- | --- |
| 物件名 | 〇〇様邸 1LDK リノベーション | ✅ |
| お客様名 | 山田 花子 | ✅ |
| 部屋の構成と寸法 | LDK 4500×4000、寝室 3000×4000（mm） | ✅ |
| 部屋のつながり | 寝室は LDK の東側に接する | ✅ |
| 天井高 | 2400mm（既定） | |
| 建具 | 玄関ドア、寝室ドア、窓 3 か所の位置 | |
| 家具 | ソファ・テーブル・ベッド など | |
| 提出期限・予算感 | | |

**すでに間取り図（画像・PDF）がある場合**は、Web CAD の「間取り画像 / PDF を読み込み」で下絵として敷き、
平面図モードで部屋ツールをなぞるほうが早い。その場合はステップ 2 を飛ばし、寸法だけ mm で整える。

## ステップ 2: 要件スペックを書く

`reference/spec-template.json` をコピーして埋める。**寸法・座標はすべて mm**。

- `rooms[]` — `name` / `width` / `depth` / `height`（既定 2400）と、位置を `x`,`z`（中心座標）か
  `attach: { to: "LDK", side: "e", shift: 0 }`（隣の部屋にぴったり接する）で指定する。
  `attach` を使うと部屋の辺が一致するので、Web CAD 側の吸着とも噛み合う。
- `openings[]` — `type`（door / window）、`room`、`side`（n/s/e/w）、`offset`（その壁の中心からの mm）。
  **部屋の境界にある壁にドアを置くと、両側の壁に開口部が開いて 2 部屋がつながる**（ルームツアーで行き来できる）。
- `furniture[]` — `type`（chair / table / sofa / bed / shelf）、`room`、部屋中心からの `x`,`z`(mm)、`rotation`(度)。
- `views[]` — 省略すると「全体パース」と「平面図」を自動で作る。これが提案書 PDF のページになる。

## ステップ 3: シーンと見積を生成する

```bash
cd .claude/skills/proposal/scripts
python3 make_scene.py    ../../../../work/spec.json -o ../../../../work/scene.json
python3 make_estimate.py ../../../../work/spec.json -o ../../../../work/estimate.md --csv ../../../../work/estimate.csv
```

- 依存パッケージなし（Python 3 標準ライブラリのみ）。
- 壁からはみ出す建具、部屋の重なり、部屋の外の家具は**警告**で知らせる（生成は続行する）。
- 単価は `reference/unit-prices.json`。**サンプル値なので実勢価格に差し替えてから使う。**
  お客様ごとに単価を変える場合は `--prices` で別ファイルを指定する。

## ステップ 4: 提案書 PDF にする

1. `npm run dev`（または配布用の `web-cad.html`）で Web CAD を開く
2. 「開く」から `scene.json` を読み込む（物件名・お客様名・アングルも復元される）
3. 家具の位置などを微調整し、見せたいアングルで「現在の視点を保存」
4. 「PDF出力」→ 表紙（物件名・お客様名・提案日）+ 1 ページ 1 アングルの A4 横 PDF

室内カットが欲しいときは「ルームツアー」で室内に入り、良い画角で「現在の視点を保存」してから PDF 出力する。

## ステップ 5: お客様に出す前の確認

- [ ] 物件名・お客様名の誤字（表紙にそのまま出る）
- [ ] 寸法が実測と合っているか（mm 表記の寸法線が平面図に入る）
- [ ] 見積の単価が最新か、除外項目（既存撤去・電気・搬入など）を注記したか
- [ ] 金額は**下書き**である旨を伝えたうえで、最終確認は人が行う

## 注意

- 見積は数量の自動算出であり、**現場条件による増減を含まない概算**。そのまま提出しない。
- お客様の氏名・住所などが入るファイルは、リポジトリにコミットしない（`work/` は .gitignore 済み）。
