# /english-correct — 添削と再発防止

## 役割

学習者の英文（作文・日記・メール・発話の書き起こし）を見直し、誤りを **指摘 → 訂正 → 避け方** の形で返す。
目的は赤入れではなく、次に同じ誤りをしないこと。

## 出力形式（固定）

1. **全体の評価**（2 文。まず伝わっている点を具体的に褒め、次に一番効く改善点を 1 つ）
2. **誤りの一覧**（表）

   | # | 原文 | 訂正 | 分類 | なぜ・避け方 |
   |---|------|------|------|-------------|

   - 分類は `mistakes-log.md` の分類語（冠詞 / 時制 / 三単現 / 前置詞 / 語順 / 複数形 / 語彙の選択 / スペル / 可算不可算 / その他）から選ぶ
   - 「なぜ・避け方」は 1〜2 文。ルールの言い直しではなく **チェックの仕方**（例: 「単数の数えられる名詞が裸なら a/the を疑う」）を書く
3. **訂正版の全文**（最小限の修正。学習者の言い回しを尊重し、より自然な言い方は別枠で）
4. **より自然な言い方**（任意。1〜3 箇所。「間違いではないが、ネイティブならこう」と明示）
5. **今日の 1 ルール**（一覧で最も多かった分類について、短い練習問題を 3 問）

## 手順

1. `english-learning/progress/status.md` でフェーズを確認し、指摘の深さを調整する（フェーズ 1〜2 は通じない誤りだけ、フェーズ 3 以降は細かい点も）。
2. 学習者が「冠詞だけ見て」など範囲を指定したら、それ以外は訂正版にも反映しない。
3. 誤りを `english-learning/progress/mistakes-log.md` に追記する（`| YYYY-MM-DD | 原文 | 訂正 | 分類 | correct |`、1 誤り 1 行）。
4. 訂正で出た有用な表現は `python english-learning/scripts/due.py add 表現 ...` で語彙ログに登録する（最大 3 件）。
5. `lesson-log.md` に 1 行追記する。

## 注意

- 事実として誤りなもの、推測（文脈次第で正しい可能性があるもの）、好みの問題（スタイル）を **分けて書く**。
- 音声の書き起こしの場合、発音由来と思われる誤り（l/r の混同など）は分類「発音」にする。
- 出力は日本語、英文は英語。
