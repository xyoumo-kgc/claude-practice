# FX 融合システム FUSION-CORE 分析スキル（賢人のデイトレード × 100億円トレーダー）

## 概要

「賢人のデイトレード」と「100億円トレーダー」（4つの鉄板エントリーパターン）の考え方を突き合わせ、
反証検証（根拠・固有性・反例の3視点）を経ても残った共通点だけを骨格にした融合FXシステム
**FUSION-CORE v1.0**（仕様: `fusion/SPEC.md`、凍結版）の判定を、チャート画像または MT5 EA のパネル値から
手作業で再現する分析スキルです。100億側の元のマニュアルは `/fx-analyze`（`.claude/skills/fx-analyze/SKILL.md`）を参照してください。

- 判定ルールと閾値は SPEC と同じです。売買判定の正解は Python 参照実装 `fusion/strategy.py`、
  運用で使う正確な値は MT5 EA `mt5/FX_Fusion_EA.mq5` のパネルです。本スキルは「同じ規則で読む目」を
  提供するもので、画像の目測には誤差があります（後述）。
- **最終検証（未接触データで1回だけ）は不合格**で、優位性は確認できていません（`fusion/RESULTS.md`）。成績の見込みを語る文書ではなく、
  同じ規則で相場を読む裁量の補助です（MT5 EA も自動売買は無効のまま、通知とパネルだけで使います）。

### 2人の共通点として残ったもの（分類つき）

分類の意味: **本質的**＝考え方だけでなく運用手順まで両者本人の発信で一致 ／ **部分的**＝考え方は共通だが
運用に差があるか片側が未確認 ／ **一般論**＝両者に当てはまるが、ダウ理論系の順張りトレーダーなら誰でも言う内容
（誤りという意味ではなく「2人固有ではない」という意味）／ **根拠不足**＝片側に本人発信がない、または循環論法の疑い。

| ID | 共通点 | 分類 | 本スキルでの位置 |
|---|---|---|---|
| C02 | 4時間足レベルの押し目・戻り目（4H MA 付近）を、1時間足のダウ転換確定（安値切上げ＋戻り高値更新）で順張りする | **本質的**（唯一） | 中核。G1・G2・トリガーの骨格 |
| C05 | 4H MA（1H の SMA80）の向き・傾きで方向を決め、その MA への押し・戻りを順張りの場所にする | 部分的 | MA 傾きゲート、G2 |
| C06 | SMA・20期間基準。1H に 20/80 を重ねる（青＝その足、赤＝上位足） | 部分的 | 指標の定義。480（日足相当）は 100億側のみで賢人側は未確認 |
| C04 | 注文集中・参加者の思惑（時間足別）から値動きを説明する相場観 | 部分的 | 節目エンジン（表示）の根。手順化しているのは賢人のみ |
| C07 | 同じ押し目構造を時間足の階層ごとに一段ずらして使う | 部分的 | ②・③・①-M15（いずれも既定 OFF） |
| C08 | ダブルトップ／ボトム＋ネックライン更新をダウ転換と等価に扱う。4H 反転・強い節目での反転 | 部分的 | ④ ラベル（表示のみ） |
| C09 | 出口は上位足の節目を目標に、固定幅でなく相場構造に沿って決済ラインを引き上げる | 部分的（賢人の分割決済は第三者観察が中心） | 4H 構造トレール |
| C01 | ダウ理論で「終了」と「転換」を分ける（転換の確定＝直近高安値の更新） | 一般論 | G1 の3条件、持続型の状態機械 |
| C03 | 損切りは根拠が崩れる位置＝直近の押し安値・戻り高値の外側 | 一般論 | SL の定義 |
| C12 | 日足との関係を確認し、日足と 4H の対立は優位性を下げる要因とみる | 一般論 | S4・戦争状態（表示のみ） |
| C13 | 環境が整わない局面では取引せず、分かりやすい局面だけを取る | 一般論 | 状態 IDLE／WATCH／ZONE |
| C14 | 事前の計画と事後の検証を回し、少数の型に習熟する | 一般論 | シナリオ表示・ログ |
| C15 | トレンドフォロー一本、逆張りはしない | 一般論 | — |

- C02 の留保: 賢人側で「4H×1H」という固定形を語るのは第三者で、本人ブログ期は「主に15分足」。骨格（4H の安値切上げと
  4H 20MA の支えを根拠に、直近高値の直上に買い注文）は本人の 2019年例で裏付きます。注文方式（指値か更新執行か）は情報源で揺れます。
- 一致の多くは**継承**で説明できます: 維新の介（大衆心理＝注文集中）→ 賢人（本人ブログのダウ理論記事で『維新流トレード術』を
  引用文献と明記）→ 100億（本人 X「勝てるようになった5ステップ」②「賢人のデイトレードの動画を死ぬほど見た」）。
  fx-analyze スキルのパターン①の記述は賢人の典型形とほぼ同文です。ただしこの X 投稿は補足調査で確認したもので、
  ローカルの検索記録では原文を再確認できていません。すべての出典は検索要約経由で、原文・動画本体は未読です。

**共通点として採用しなかったもの**（片側の要素としてだけ扱う）
- **C11 収束→拡散**（1H MA が 4H MA に収束してから拡散する局面を狙う）: 100億本人の語彙（X 2022-12-13）ですが、
  賢人本人の発信に記録がなく、賢人側の根拠は 100億も研究する第三者の解釈だけで循環論法の疑いがあり、反例もあります。
  → **100億由来**として S6 の収束（conv）に表示するだけ。
- **C10 前方の反対勢力と RR で見送る**: 100億本人（X「近くに抵抗勢力がいないか」「RR1:2以上」）は確かです。賢人側の代表句
  「取るリスク以上のリワード…」は 100億のブログが賢人ツイートを言い換えた文言で、逆向きの循環です。
  → **100億由来**として S5・rr_cf に表示するだけ（見送りにはしない）。
- **C16 損切りを必要経費として受け入れる**: 賢人は本人発信あり。100億側は fx-analyze スキルに記述がなく、根拠は 100億ブログによる
  賢人ツイートの解説のみ。→ 継承の傍証にとどめ、共通点には数えない。

### 融合ツールが選んだ解釈（独自の部分）

両者に数値の出典はほとんどありません。次は本ツール（SPEC）の選択であり、両者の「本人の言」ではありません。
出典タグ: ［共通］反証検証を通過した共通点 ／［100億］本人 ／［賢人］本人 ／［第三者］解説者の解釈 ／
［設計］出典のない仮置き ／［実データ］開発期間（IS）の実データで README 規則3により採否を決めたもの。

| 選択 | タグ | 補足 |
|---|---|---|
| 判定はすべて 1H 足だけで行い、上位足は換算 MA（SMA80・SMA480）とスイングの深さ（12本・72本）で表す | 設計 | H4／D1 を再集計しないので、時差・日曜足による Python と MQL5 の食い違いが起きない |
| 4H MA は「最低でも水平」＝ slope80 ≥ 0。窓は 12本（4H 足3本） | 賢人 X15・100億「80MA の方向」→ 数値は設計 | IS で外すと取引が増え成績も僅差で良かったが、規則3で有意でないため出典どおりゲートに残した［実データ］ |
| 押しが 4H MA の 0.5ATR 以内に届いたら「場所」成立（G2） | 共通 C02・C05 → 数値は設計 | |
| 逆指値＝戻り高値 + 0.05ATR（終値での確認を待たない） | 賢人 2019年例「直近高値の直上に買い注文」／100億 STEP4「転換確定の瞬間」→ 数値は設計 | 「安値切上げ＋高値更新の確定」をブレイクそのもので執行する |
| SL＝戻り高値以降の最安値（runLow）− max(0.2ATR, 3×名目スプレッド) | 共通 C03 → 位置の細則は設計・審査 | 底 L0 への退避はしない。R が 0.8ATR 未満なら見送り |
| R は 0.8〜3.0 ATR の範囲だけ | 設計 | 出典なし |
| 日足はゲートにせず、スコア（S4）と「戦争状態」の表示だけ | 100億 要素①（禁止）と賢人（度合い）の折衷＝D01 | 「戦争状態」の語は出典未確認で定義も二通りなので条件式に置き換えた。100億準拠の見送り（F+d1）は、最終検証で fusion との差が有意でなかった |
| 背後の支え（HZ・FLIP・KEY。MA は数えない）は表示のみ | 賢人 X01・K04 | 賢人本人は「支えのない押し目は非常にリスクが高い」とするが、見送りにする F+support は最終検証で fusion との差が有意でなく、見送りにはしない |
| 前方の反対勢力＝現在の波の極値より先の強い節目（touch≥3）＋日足 MA。押しの起点は数えない | 100億 要素② → 定義は設計 | 前身の「藁人形テスト」（押しの起点高値を反対勢力に数えた）を是正。表示のみ（見送りにする F+clear は最終検証で fusion との差が有意でなかった） |
| 節目＝4H MA の「山」の高値・「谷」の安値を 0.6ATR で束ね、日足級は重み2 | 賢人 X12・K03 → 数値は設計 | |
| 出口は「4H 構造トレール」と「週末・休場決済」の2つだけ。分割・建値移動・固定利確・時間決済なし | 実データ（規則3で合格）・100億 X05 | 両者の実例（分割決済）とは違う出口。裁量で加えると別の戦略になる |
| スコア S1〜S6 は足切りに使わない | 実データ | IS でスコアと成績が単調でなく、A 以上に絞ると取引が6割減って前身 4P-Score の失敗を繰り返す |
| ③（日足押し × 4H 終了兆候）は既定 OFF、④ はラベルのみ | 実データ | 2つの設計案の実測でともに負け越し |
| ロット（risk_percent） | 外部パラメータ | 両者の手法に由来しない。SPEC §12.3 の既定 1.0%、推奨 0.5%（MT5 EA の `InpRiskPercent` は既定 0.5%） |

## 使い方

```
/fx-fusion
```

引数なしで起動すると、対話形式で分析に必要な情報を収集します。通貨ペアを添えて起動してもよい
（例: `/fx-fusion EURUSD`）。チャート画像を添付した場合はそれを読み、足りない情報だけを質問します。

## スキル実行手順

### ステップ1: 情報収集

起動時の引数: $ARGUMENTS （通貨ペアが含まれていればそれを使う。空なら質問する）

次のいずれかの入力をユーザーから受け取ってください。足りないものは質問し、推測で埋めないこと。

**A. チャート画像**（推奨。すべて同じ銘柄・同じ時刻のもの）
1. **1時間足**: 直近 200本以上（できれば 400本＝約3週間）。SMA20（青）・SMA80（赤）・SMA480（黄）と ATR14 を表示したものが望ましい。判定の主役。
2. **4時間足**: 直近 150本以上（約1か月）。4H レベルのスイングと節目の確認用（1H で 12本を数える代用）。
3. **日足**: 直近 150本以上（約7か月）。日足レベルの状態（T_D1）・日足級の節目・SMA20（＝1H の SMA480）の確認用。
- 画像に表示されていない指標・時刻・スプレッドは質問する。
- 日足の画像がなければ、日足に関わる項目は「不明」とし、スコアは中立値（S4＝10、S6 の乖離部分＝8）にする（SPEC §2.7 と同じ扱い）。
- 1H の本数が足りず 4H レベルの高値・安値を2つずつ拾えないときは、4H チャートで左右3本の近似を使い「近似」と明記する。

**B. MT5 EA（`mt5/FX_Fusion_EA.mq5`）のパネル値**
- 状態、G1（UP/DOWN/NEUTRAL と理由）、T_D1／T_BIG／T_SMALL と END、戦争状態、depth、slope80、gap、conv、R/ATR、
  スコア内訳 S1〜S6 とグレード、直近の理由コード、待機注文（price・SL・TP1）、建玉（SL・R・MFE）、エリア判定、次の暦イベント。
- パネル値がある項目は目測より優先する（パネル値が正）。

**C. 数値だけ**（ユーザーがチャートから読み取った値）
- 直近の 4H レベル高値2つ・安値2つ、押しの起点以降の 1H 戻り高値とその直前の安値、戻り高値以降の最安値、
  現在の確定足の終値、SMA80・SMA480・SMA20、ATR14、スプレッド。

**共通で必ず確認するもの**
4. **通貨ペア**（既定の監視リスト: USDJPY, EURUSD, GBPUSD, AUDUSD, USDCAD, EURJPY, GBPJPY, XAUUSD）
5. **現在のサーバー時間と曜日**（時刻ルール用。サーバー時間＝NY 時間＋7時間が前提。違うブローカーなら時差を聞く）
6. **スプレッド**（不明なら後述の名目スプレッド s_nom を使う）
7. **既に EA の待機注文・建玉があるか**（ある場合は出口計画を主に出す。同じセットアップで約定済みなら R06）
8. 任意: 口座残高と許容リスク%（ロット計算をするときだけ）

### ステップ2: 共通の前提（1H 単一時間足への換算）

| 要素 | 定義（SPEC §1〜§4） | チャート画像からの読み方 |
|---|---|---|
| 4H MA | 1H の **SMA80**（終値の単純移動平均） | 1H の赤線。1H がなければ 4H チャートの SMA20 で近似（足の区切りの差で数 pips ずれる） |
| 日足 MA | 1H の **SMA480** | 1H の黄線。日足チャートの SMA20 で近似 |
| 1H MA | 1H の SMA20 | 1H の青線。S6 の収束判定にだけ使う |
| ATR | **ATR14（1H）**。TR＝max(高値, 前終値)−min(安値, 前終値) の14本単純平均 | 表示があればその値。なければ直近14本の値幅（高値−安値）を平均する。桁合わせの目安は主要通貨ペアで価格の 0.1% 前後（EURUSD 1.10 なら約10pips）、GOLD はその2〜3倍。相場つきで倍半分は変わるので、必ず直近14本から見積もる |
| 1H レベルのスイング（SMALL） | 深さ **N＝3**: 左右3本より高い高値（新しい側は厳密に高い、古い側は以上）／低い安値 | 1H で左右3本を数える。右側3本が確定するまで認識しない（画像右端の3本には確定スイングはない） |
| 4H レベルのスイング（BIG） | 深さ **N＝12**（4H 足3本相当） | 1H で左右12本を数える。4H チャートなら左右3本で近似。右端12本（4H で3本）はまだ確定していない |
| 日足レベルのスイング（D1） | 深さ **N＝72**（日足3本相当） | 日足チャートで左右3本。右端3日分は未確定 |
| 確定足 t | 判定はすべて確定した 1H 足の終値で行う | 画像の最右の足が形成中なら、その1本前を「現在の足 t」として読む |
| 方向 d | +1＝買い、−1＝売り。以下は買いで書く。売りは高値と安値・max と min・不等号をすべて反転する | |

スイングの数え方の注意
- ヒゲを含む高値・安値で数える（終値ではない）。
- 同値の高値が並ぶときは、古い側が「以上」なので**新しい方**がスイングになる。
- 4H レベルのスイングは必ず 1H レベルのスイングでもある（12本の条件は3本の条件を含む）。
- 「スイングは N 本後に初めて認識する」ため、画像の時点で使えるのは右端から N 本以上離れたものだけ。

### ステップ3: G1 — 4H レベルのダウ構造（既定のゲート）［共通 C01・C02］

直近に確定した 4H レベルの高値2つ（BH[0] 新・BH[1] 旧）と安値2つ（BL[0]・BL[1]）を取る。各2個そろわなければ **R01**。

```
買い（UP）  : BH[0] > BH[1]（高値更新）かつ BL[0] > BL[1]（安値切上げ）かつ 終値 C[t] > BL[0]（押し安値を割っていない）
              → 押しの起点 j_peak ＝ BH[0] の足
売り（DOWN）: BL[0] < BL[1] かつ BH[0] < BH[1] かつ C[t] < BH[0]   → j_peak ＝ BL[0] の足
どちらでもない → NEUTRAL（R01）
```

「終了≠転換」（C01）の表れ方
- 高値更新＋安値切上げでも、終値が押し安値 BL[0] 以下なら上昇は「終了」。UP 扱いしない（売りにもしない）。
- 高値切下げ（LH）が出ただけなら NEUTRAL。反対側の LH＋LL（安値更新）が確定して初めて DOWN。
- 買いと売りは排他で、同時には成立しない。

画像からの読み方
- 1H チャートで右から左へ、左右12本より高い高値を2つ、低い安値を2つ拾う。4H チャートなら左右3本で近似。
- 「現在の押し」の安値はまだ確定していない（右側12本が経っていない）ことが多い。その場合 BL[0] は押しの起点より前の安値
  （前の押し安値）になる。これで正常。
- 境界（BH[0] と BH[1] がほぼ同値、終値が BL[0] のすぐ上）では目測で判定が割れる。「境界付近・要確認」と明記する。

G1 不成立 → **状態 IDLE**。反対側シナリオを数式で添える（例: 「BIG 安値 {BL[0]} を終値で割り、さらに LH&LL が確定すると売り目線」）。

### ステップ4: MA 傾きゲート（既定のゲート）［共通 C05／賢人 X15／100億「80MA の方向」］

```
slope80 ＝ (SMA80[t] − SMA80[t−12]) / ATR[t] × d    （12本＝4H 足3本）
slope80 ≥ 0（SLOPE_MIN。4H MA が最低でも水平）でなければ R08
```

画像からの読み方
- 1H の赤線（SMA80）の現在値と 12本前（4H チャートなら3本前）を比べる。買いなら上向きか横ばいで ○、下向きで ×。
- S1 の「≥ 0.10 で 20点」は、12本で ATR の1割（EURUSD なら 1pip 前後）という微小な傾きで、目測では区別できない。

### ステップ6: 1H 転換トリガー（厳密定義）［共通 C02・C01・C08］

買い（売りは鏡像）
```
SH     ＝ 直近に確定した 1H レベルの戻り高値（左右3本）。SH が押しの起点 j_peak と同じかそれ以前なら R03
L0     ＝ SH の直前の 1H レベル安値（底）。直近6個の 1H 安値から探す。なければ R03
runLow ＝ SH の次の足から現在までの最安値（切上げ安値の候補）
条件A（安値切上げの維持）: runLow > L0                       でなければ R04
条件B（未消化）          : SH の後に終値で SH を越えた足がない   越えていれば R05（この構造は消化済み）
key    ＝ (方向, SH の足)。同じ key で約定済みなら R06（1セットアップにつき約定1回）
```

売り: SH の代わりに「j_peak より後の直近確定 1H 安値（以下 SH'）」、L0 の代わりに「SH' の直前の 1H 高値 H0」。
runHigh ＝ SH' 以降の最高値。条件A は runHigh < H0、条件B は SH' の後に終値で SH' を割った足がないこと。
逆指値は SH' − 0.05ATR、SL は runHigh + バッファ。

形のイメージ（買い）
```
 j_peak（4H 高値＝押しの起点）
   ●
    \                 逆指値 price ＝ SH + 0.05ATR ──┐
     \        SH（1H 戻り高値）                      │ ← ここを上抜けた瞬間に約定（安値切上げ＋高値更新の確定）
      \        ●───────────────────────────────────┘
       \      / \         /
        \    /   \       /    ← runLow（SH 以降の最安値）が L0 より上なら条件A
         \  /     \_____/        SL ＝ runLow − max(0.2ATR, 3×スプレッド)
          \/
          ● L0（SH 直前の 1H 安値＝底）
 - - - - - - - - - SMA80（4H MA）: 押しの最安値がこの線の 0.5ATR 以内か、割っていれば G2
```

画像からの読み方
- 起点の 4H 高値より右で、左右3本より高い 1H の高値を探す。**最も新しいもの**が SH（複数あっても最新の1つだけ）。
- SH の左側で最初に出てくる、左右3本より低い安値が L0。
- SH の右側（画像右端まで）の安値がすべて L0 より上か（条件A）。1本でも L0 以下があれば R04。
- SH の右側に SH より上で引けた足があれば R05（既にブレイク済み。次の戻り高値を待つ）。
- SH は右側3本が確定していなければまだ存在しない。画像右端から3本以内の高値は候補にならない。

G1・G2・MA 傾き ○ で R03〜R05 → **状態 ZONE**（トリガー待ち）。「{SH 候補} の右側3本の確定を待つ」「L0 {価格} を割ると R04」
のように待つべきことを書く。

### ステップ7: 注文価格・SL・R

```
price ＝ SH + d × 0.05 × ATR                      ← 逆指値（BUY STOP／SELL STOP）
buf   ＝ max(0.2 × ATR, 3 × s_nom)               ← スプレッド下限つきバッファ
SL    ＝ runLow − d × buf                          ← 切上げ安値の外側［共通 C03］
R     ＝ (price − SL) × d
R < 0.8 × ATR → R09（見送り。底 L0 への退避はしない）
R > 3.0 × ATR → R10（見送り。①-M15 降格は既定 OFF）
```

- 名目スプレッド s_nom（価格単位）: EURUSD 0.00010 ／ GBPUSD 0.00015 ／ USDJPY 0.010 ／ EURJPY 0.015 ／ GBPJPY 0.025 ／
  AUDUSD 0.00012 ／ USDCAD 0.00015 ／ AUDJPY 0.015 ／ XAUUSD 0.30
- R は価格単位と pips の両方で示す（JPY ペアは 0.01＝1pip、他は 0.0001、XAUUSD は USD）。R/ATR も併記する。
- ロット（任意。両者の手法に由来しない外部パラメータ）: ロット＝floor(残高 × risk% ÷ (R ÷ tick_size × tick_value) ÷ lot_step) × lot_step
  を [最小, 最大] に丸める。risk_percent は SPEC §12.3 の既定 1.0%・推奨 0.5%（MT5 EA の `InpRiskPercent` の既定は 0.5%）。
- 毎 1H 確定で ATR と runLow が変わるので price・SL は置き直される。レポートの値は「画像の時点の値」であることを明記する。
- R09／R10 → **状態 ZONE**（R が枠外。runLow が上がる、または ATR が変わるのを待つ）。

すべて成立 → **状態 ARMED 相当**（EA ならここで逆指値を置き、通知する）。

### ステップ8: 情報項目（既定ではゲートにしない。表示・スコア・事後検証用）

**8-1 日足との関係 rel と戦争状態**［C12（一般論）／D01］
- 日足の状態 T_D1 は、日足レベルのスイング（左右3本）に対する持続型のダウ状態で読む。
  - 最新の確定した日足レベル高値を**終値で上抜け**た時点で、その上抜けまでの最安値が「その高値より前の最新の日足レベル安値」
    より高ければ **上昇（+1）**。安値が切り上がっていなければ「下降の終了」で **0**。下抜けは対称に **下降（−1）**。
    以後は反対側のイベントが起きるまで維持する。
  - END（終了の兆し）: 上昇中に、押し安値以降の確定高値がそれまでの最高値より低い（高値切下げ）。下降は対称。

  アブレーション F+d1 として最終検証で評価し、fusion との差は有意でなかった。既定では見送らない）。

## 正直な注意書き（レポートのたびに必ず伝える）

1. **最終検証（未接触データで1回だけ）は不合格**で、v1.0 は「優位性なし」と記録されています（`fusion/RESULTS.md`）。
   平均 +0.055R/回（95%区間 −0.049〜+0.163R）で、ゼロとも、トレンド方向にでたらめに入る素朴なやり方とも区別できませんでした。
   MT5 EA の自動売買は無効（既定 OFF）のまま、シグナル通知とパネル表示を裁量の補助として使います。
   - 設計時の開発期間（2013〜2017）の成績は約190構成の探索から選んだもので、選択バイアスを含みます。
   - 前身 MinCore の審査ホールドアウト: 2010〜2012 は PF1.06、AUDUSD・USDCAD 2013〜2017 は PF0.76。
   - 比較対象の従来版 EA・4P-Score も、実データの検証期間ではマイナスでした（`fusion/README.md`）。
2. **勝率は 25〜30% 前後、損益の中央値は −1R、利益は週末まで持った少数の取引に集中し、10〜20連敗は想定内**です
   （SPEC §16 の固定文言）。1取引の R の標準偏差は約 2.7R で、1銘柄10か月では優位性の有無を判定できません。
3. **分割決済・建値移動・早利確・時間決済を裁量で加えると別の戦略になり**、検証の対象外になります。
   両者の実例（分割決済）とも違う出口であることを理解したうえで使ってください。
4. **画像からの目測には誤差**があります（スイングの認定 ±1本、MA・ATR の読み取り ±10〜20%、価格は目盛り間隔に依存）。
   depth ≤ 0.5、slope80 ≥ 0、runLow > L0、R の上下限などの**境界では判定が割れます**。境界付近は「要確認」と明記し、
   正確な値は MT5 EA（`mt5/FX_Fusion_EA.mq5`）のパネルで確認してください。
5. 本スキルは EA の履歴（約定済み key、累計成績）を持たないため、R06 と累計成績は答えられません。
6. **投資助言ではありません**。売買の判断と結果はユーザー自身の責任です。SPEC §16 の段階（通知のみでチャートを確認 1〜3か月
   → デモで自動売買 → 少額の実運用）を守ってください。v1.0 は最終検証で不合格のため、通知のみの段階から先には進みません。
7. 数値は SPEC v1.0（凍結）と同じです。SPEC が v1.1 に改訂されたら本スキルも更新します。

## 用語集

| 用語 | 説明 |
|---|---|
| 押しの起点 j_peak | G1 で確定した直近の 4H レベル高値（売りは安値）。ここから現在までが「押し」の窓 W |
| 戻り高値 SH | 押しの内側で直近に確定した 1H レベル高値。これを上抜ける瞬間が転換確定＝逆指値の位置 |
| 底 L0 | SH の直前の 1H レベル安値。これを割ると安値切上げが崩れる（R04） |
| 切上げ安値 runLow | SH 以降の最安値。SL の基準（底 L0 ではない） |
| depth | 押しの最安値と SMA80 の距離（ATR 単位）。0 以下＝到達・貫通 |
| slope80 | SMA80 の 12本の変化（ATR 単位、方向つき）。4H MA の向き |
| gap／conv | SMA80 と SMA480 の乖離／SMA20 と SMA80 の収束（ATR 単位）。S6 用 |
| 節目・touch | 4H MA の山谷から作る水平線と、その反応回数（日足級の点は2回分） |
| HZ／FLIP／KEY | 背後の支えの3種類: 水平帯／レジサポ転換／前の押し安値 |
| TH_run | 押しの起点以降の最高値＝現在の波の極値。目標であって反対勢力ではない |
| CF／rr_cf | 前方の反対勢力（TH_run より先の強い節目＋日足 MA）と、そこまでの距離（R 単位） |
| TP1／TP2 | 目標の目安（表示のみ。固定利確はしない） |
| R | 逆指値と初期 SL の差＝1取引のリスク単位。成績はすべて R で数える |
| 理由コード | R01 G1 不成立、R02 G2 不成立、R03 SH／L0 なし、R04 切上げの崩れ、R05 消化済み、R06 約定済み、R08 MA 傾き、R09／R10 R の枠外。R07・R11〜R16 は既定 OFF のアブレーション用 |
| 状態 | IDLE／WATCH／ZONE／ARMED／FILLED／EXITED／PAUSED |
| 戦争状態 | T_D1 ≠ 0 かつ T_BIG ＝ −T_D1 かつ END_BIG ＝ 0。表示のみ |
| T_D1／T_BIG／T_SMALL、END | 日足／4H／1H レベルの持続型ダウ状態（+1／0／−1）と終了の兆し |
| GAP_FALLBACK | 休場明け（12時間以上の空き）に建玉を始値で全決済する規則 |
| s_nom | 名目スプレッド（銘柄ごとの固定値）。SL バッファの下限 3×s_nom に使う |
