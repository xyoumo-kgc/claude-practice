# /english-lesson — 毎日のレッスン

## 役割

`english-learning/curriculum/02-daily-lesson.md` の固定形式で、**15〜20 分で終わる** 1 回分のレッスンを作る。

## 手順

1. `english-learning/progress/status.md` で現在のフェーズを確認する。`english-learning/progress/lesson-log.md` の直近 5 件を見て、テーマと文型が重複しないようにする。
2. テーマを決める。引数があればそれ、なければフェーズ別テーマ例（`02-daily-lesson.md` 末尾）から未実施のものを選ぶ。
3. 以下の 5 パートを **必ずこの順・この分量** で出力する。
   1. **今日の語彙**（6〜8 個）: 表形式で 英語 / 発音記号 / 意味 / 例文。例文はそのテーマの会話で本当に使う文にする。
   2. **文の形成**（1 つの型）: 型を図示 → 例 3 つ → 学習者が自分の情報で 3 文作る空欄。語彙パートの語を再利用する。
   3. **発音ガイド**（1 つの音）: 口の形、日本語との違い、ミニマルペア 3 組、早口言葉 1 つ。日本語話者が苦手な音（/r/ /l/ /θ/ /ð/ /v/ /f/ /æ/ /ʌ/ /ə/、語尾の子音、強勢）から選ぶ。
   4. **実践演習**（穴埋め 5 → 並べ替え 3 → 日→英 3）: 解答は `<details>` にまとめ、「よくある間違い」を 2 つ添える。
   5. **記録**: 下記のとおりログを更新する。
4. 学習者が演習の答えを送ってきたら採点し、誤りを `english-learning/progress/mistakes-log.md` に追記する（`| 日付 | 誤り | 訂正 | 分類 | lesson |`）。

## ログの更新

- 新出語彙と今日の文型を、リポジトリルートから次のコマンドで追加する（語彙は「語彙」、定型表現は「表現」、文型は「文法」）:

  ```bash
  python english-learning/scripts/due.py add 語彙 "grab a bite" "軽く食べる" "Let's grab a bite." lesson
  ```

- `lesson-log.md` に 1 行追記する: `| YYYY-MM-DD | lesson | テーマ / 文型 / 音 | 15分 | （空欄） |`
- `status.md` の「最終学習日」「連続学習日数」を更新する。

## 注意

- 分量を増やさない。学習者が「もっと」と言っても翌日に回す。
- フェーズ 1〜2 は例文を短く（5 語以内目安）、フェーズ 3 以降は接続詞入りの文にする。
- 出力は日本語、英語素材は英語。発音の説明はカタカナで代用せず、発音記号と口の形で説明する。
