# 英語マスター学習計画（5フェーズ）

日本語話者の大人が、ゼロから「実生活で困らずに英語でやり取りできる」状態（CEFR B1〜B2 相当）に到達するための計画。
1日 **15〜25分** を毎日続ける前提で組んである。

> **期間について（推測）**: 各フェーズの週数は「毎日15〜25分」を守った場合の目安であり、個人差が大きい。
> CEFR の到達目安時間（A1 約 100 時間、A2 約 200 時間、B1 約 400 時間、B2 約 600 時間・いずれも累計）は
> 各種語学試験団体が公表する概算値で、確定した事実ではない。**週数より「卒業チェック」を満たしたかで進級を判断する。**

## 全体像

| フェーズ | テーマ | 到達レベル | 目安期間 | 主に使うスキル |
|---------|--------|-----------|---------|---------------|
| 0 | 準備・診断 | ― | 1週 | `/english-plan` |
| 1 | 初心者向けの基礎 | A1 | 8〜12週 | `/english-lesson` `/english-review` |
| 2 | 日常会話スキル | A1→A2 | 8〜12週 | `/english-chat` `/english-lesson` |
| 3 | 文の構築 | A2 | 8〜12週 | `/english-correct` `/english-lesson` |
| 4 | 文法の理解 | A2→B1 | 12〜16週 | `/english-grammar` `/english-correct` |
| 5 | 実生活での実践的なコミュニケーション | B1→B2 | 継続 | `/english-roleplay` `/english-chat` |

`/english-review`（間隔反復）は **全フェーズで毎日** 使う。忘却を防ぐ土台になる。

## 学習の原則（全フェーズ共通）

1. **毎日少しずつ**。週1回2時間より、毎日20分のほうが定着する（間隔反復の前提）。
2. **声に出す**。読むだけの学習は会話に転移しにくい。すべての例文を音読・シャドーイングする。
3. **間違いは資産**。`progress/mistakes-log.md` に貯め、`/english-review` で弱点だけ集中して潰す。
4. **チャンク（かたまり）で覚える**。単語単独ではなく「Could I have 〜?」のような使えるかたまりで記憶する。
5. **完璧より通じること**。フェーズ2以降は、文法の正確さより「伝わったか」を先に評価する。

## 1週間の基本ルーティン（例）

| 曜日 | 内容 | 時間 |
|------|------|------|
| 月・水・金 | `/english-review`（5分）→ `/english-lesson`（15分） | 20分 |
| 火・木 | `/english-review`（5分）→ `/english-chat`（15分） | 20分 |
| 土 | `/english-roleplay`（20分） | 20分 |
| 日 | `/english-review` まとめ復習（10分）→ 週の振り返り（`progress/status.md` 更新） | 15分 |

フェーズ1〜2 では `/english-chat` の代わりに `/english-lesson` を増やしてもよい。フェーズ3 以降は `/english-correct` を週1回入れる。

## フェーズ0: 準備・診断（1週）

**目的**: 現在地を知り、習慣の器を作る。

- `/english-plan` でレベル診断（簡単な自己紹介・質問応答・短文の読み書き）を受け、`progress/status.md` を記入する
- 学習する時間帯を固定する（起床後・通勤中・寝る前など）
- 音声入力ができる環境（スマホの音声入力でも可）を用意する。発音練習で使う

**卒業チェック**: `status.md` に開始日・フェーズ・週の予定が入っている。

## フェーズ1: 初心者向けの基礎（A1・目安 8〜12週）

**目的**: 英語の「音」「最重要語」「一番シンプルな文」を体に入れる。

### 学ぶこと

| 領域 | 内容 |
|------|------|
| 音 | アルファベットの音（名前でなく音）、日本語にない音（/r/ /l/ /θ/ /ð/ /v/ /f/、母音 /æ/ /ʌ/ /ə/）、単語の強勢 |
| 語彙 | 最頻出 **300〜500語**（人・物・場所・数・時間・曜日・月・色・食べ物・家族・基本動詞 30 個） |
| 文 | be動詞の文（I am / You are / It is）、一般動詞の現在形、否定文、Yes/No 疑問文、5W1H 疑問文 |
| 定型表現 | あいさつ、自己紹介、お礼・謝罪、聞き返し（Sorry? / Could you say that again?） |

### 毎日のやり方

1. `/english-review`（5分）: 前日までの語彙を復習
2. `/english-lesson`（15分）: 新語 6〜8 個 + 文型 1 つ + 発音 1 ポイント + 演習
3. すべての例文を **3回音読**

### 卒業チェック（すべて Yes で進級）

- [ ] 自己紹介を 5 文で言える（名前・出身・仕事/学校・好きなこと・今日の予定）
- [ ] 「What / Where / When / Who / How」で始まる質問に単文で答えられる
- [ ] 語彙ログの Box 3 以上が 200 件を超えている
- [ ] /r/ と /l/、/θ/ を意識して発音し分けられる（完璧でなくてよい）

## フェーズ2: 日常会話スキル（A1→A2・目安 8〜12週）

**目的**: 決まった場面で「とりあえず言える・聞ける」ようになる。正確さより流暢さ。

### 学ぶこと

| 場面 | 主な表現 |
|------|---------|
| 注文 | Can I have 〜? / I'd like 〜 / For here or to go? / Could I get the check? |
| 買い物 | How much is this? / Do you have this in 〜? / I'm just looking. |
| 道案内 | Where is 〜? / How do I get to 〜? / Go straight, turn left |
| 情報を尋ねる | What time does 〜 open? / Is there a 〜 near here? |
| おしゃべり | How's it going? / What do you do? / I like 〜 / Me too / Really? |
| 困ったとき | Sorry, I don't understand. / Could you speak more slowly? / What does 〜 mean? |

- 語彙を **800〜1,000語** に増やす（場面ごとのチャンクで）
- 過去形（I went / I had）と未来（I'm going to / I will）を「使える」レベルで導入する

### 毎日のやり方

- `/english-chat`（会話パートナー）を週 2〜3 回。簡単な質問から始まり、正解するたびに難しくなる
- `/english-lesson` は場面別語彙に切り替える
- 聞き取り: 例文を耳で聞いて（音声合成でも可）真似る **シャドーイング** を毎回 2 分

### 卒業チェック

- [ ] レストランで注文〜会計まで英語だけで通せる（`/english-roleplay` で確認）
- [ ] 昨日したこと・明日する予定を 3 文ずつ言える
- [ ] 分からないときに英語で聞き返せる
- [ ] `/english-chat` で 10 往復続けられる

## フェーズ3: 文の構築（A2・目安 8〜12週）

**目的**: 単語の羅列から、「自分の言いたいこと」を文にして組み立てられるようになる。

### 学ぶこと

| 項目 | 内容 |
|------|------|
| 語順 | 英語は **主語→動詞→残り** の順が絶対。日本語との語順の違いを体で覚える |
| 5つの基本文型 | SV / SVC / SVO / SVOO / SVOC を「型」として使う |
| 文をつなぐ | and / but / so / because / when / if / before / after |
| 長くする | 形容詞・副詞・前置詞句（in the morning / at the station / with my friend）を足す |
| 質問を作る | 語順の入れ替え、do/does/did、疑問詞 + 一般動詞 |
| 書く | 1 テーマ 5 文の短い段落（自己紹介、昨日の出来事、好きなもの） |

### 毎日のやり方

- `/english-lesson` の「文の形成」パートを厚くする（1 つの型で 5 文作る）
- 週 1〜2 回 `/english-correct` に短い段落を提出し、添削と「避け方」を受ける
- 添削で出た間違いは `mistakes-log.md` に自動で溜まる → `/english-review` で復習

### 卒業チェック

- [ ] 5 文の段落を、辞書を見ずに 5 分で書ける
- [ ] because / when / if を使った文を即興で言える
- [ ] `/english-correct` の指摘が 1 段落あたり 3 件以下になる
- [ ] 語彙ログが 1,200 件を超えている

## フェーズ4: 文法の理解（A2→B1・目安 12〜16週）

**目的**: これまで「感覚」で使ってきた文法を整理し、時制・助動詞・複文を自在に使う。
**理論から入らず、会話例から入る**（`curriculum/03-grammar-simplified.md` の方針）。

### 学ぶ順番（推奨）

1. 時制の全体像: 現在・過去・未来 × 単純・進行
2. 現在完了（経験・継続・完了）と過去形の使い分け ← 日本語話者の最難関
3. 助動詞: can / could / should / must / have to / might / would
4. 冠詞 a / the / 無冠詞 と 可算・不可算
5. 前置詞: 時間（at / on / in）、場所（at / in / on）、方向（to / for / into）
6. 比較: -er / more / the -est / as 〜 as
7. 関係代名詞: who / which / that
8. 受動態
9. 仮定法: If I were 〜 / If I had 〜
10. 間接話法・間接疑問: I don't know where he is.

### 毎日のやり方

- `/english-grammar 〈項目〉` で会話例つきの説明 → その場で自分の例文を 3 つ作る
- `/english-correct` を週 2 回。文法項目を指定して集中添削（例: 「冠詞だけ見て」）
- `/english-review` の「文法」種別を必ず混ぜる

### 卒業チェック

- [ ] 上記 10 項目それぞれで、自分の例文を即興で言える
- [ ] 過去形と現在完了を使い分けて、旅行の話を 1 分できる
- [ ] `/english-correct` で「時制」「冠詞」の指摘が週に 2 件以下

## フェーズ5: 実生活での実践的なコミュニケーション（B1→B2・継続）

**目的**: 実際の状況で目的を達成する。ここからは「勉強」より「使う」。

### 練習する状況（`/english-roleplay`）

| 分類 | シナリオ例 |
|------|-----------|
| 旅行 | ホテルのチェックイン・トラブル（部屋が違う）、空港の入国審査、レンタカー、道に迷った |
| 生活 | 病院で症状を説明、銀行口座、携帯の契約、アパートの内見、苦情を言う |
| 買い物 | 市場で値切る、返品・交換、店員に相談 |
| 仕事 | 就職面接、自己PR、電話会議の発言、メール、雑談（スモールトーク） |
| 社交 | 初対面の会話、意見を言う・賛成/反対、誘う・断る、ストーリーを語る |

### 毎日のやり方

- `/english-roleplay` を週 2 回以上。終わりに出る「役立つ表現リスト」を語彙ログへ
- `/english-chat` を「意見を言う」「経験を語る」テーマで
- 本物のインプット（ニュース・ポッドキャスト・動画）を 1 日 5 分。分からない表現を `/english-grammar` に聞く
- 可能なら実際の人と話す機会（オンライン英会話・言語交換）を月 2 回以上

### 卒業チェック（B2 相当の目安）

- [ ] 初めてのシナリオでも、目的（予約・苦情・依頼）を英語で達成できる
- [ ] 自分の意見と理由を 1 分以上話せる
- [ ] 相手が普通の速さで話しても大意がつかめる
- [ ] 間違いログの新規追加が週 3 件以下

## つまずいたときの対処

| 症状 | 対処 |
|------|------|
| 単語が覚えられない | 例文ごと覚える。`/english-review` を 1 日 2 回に増やす |
| 話すと固まる | `/english-chat` の難易度を一段下げる（「もっと簡単に」と言えばよい） |
| 文法が頭に入らない | 理論を捨てて `/english-grammar` の会話例を音読する。ルールは後から付いてくる |
| モチベーション低下 | フェーズを 1 つ戻して「できる」体験をする。連続学習日数を `status.md` で見る |
| 忙しくて時間がない | `/english-review` 5 分だけは死守する。ゼロの日を作らない |
