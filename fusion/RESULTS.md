# 最終検証の結果：FUSION-CORE v1.0（未接触データで1回だけ評価）

[事前登録](PREREGISTRATION.md)どおりに、まだ誰も成績を見ていないデータで1回だけ評価しました。
結果は良くても悪くてもそのまま載せる約束です。全部の表は [results/final_eval_report.md](results/final_eval_report.md)、
全部の数値は [results/final_eval_results.json](results/final_eval_results.json) にあります。

## 結論

**判定は不合格です。** 合格基準 P1〜P6 を一つも満たしませんでした。v1.0 は「実データで優位性を確認できなかった」と記録します。

- 未接触の7銘柄・約15年分で1,609回取引し、平均は +0.055R/回でした。95%区間は −0.049〜+0.163R、t は1.07 です。**ゼロと区別できません。**
- 同じ出口（構造トレール・週末決済）を使い、トレンド方向に**でたらめな時刻で入る**素朴なやり方は平均 +0.019R でした。
  FUSION-CORE の「押し目・戻り目と1時間足の転換を待つ」入り方が上乗せした分（+0.036R）は、偶然の範囲です（P4）。
- 利益は週末まで持った少数の大きな勝ちに頼っています。上位1%（17件）を除くと平均 −0.058R です（P5）。
- 2018〜2020年（U-B）は平均 −0.069R（PF0.90）でした。

**比較対象との比較**
- 点推定では fusion が比較対象すべてを上回りました。
  - 100億の要素だけ（oku_only）：−0.022R
  - 賢人の要素だけ（kenjin_only）：−0.166R
  - 従来版EA：−0.007R
  - 4P-Score：−0.027R
- ただし、どれも事前に決めた「勝ち」の基準（区間が0をまたがない）には届きません。

**事前登録 §11 に従った扱い**
- MT5 EA の自動売買は既定 OFF のままにします。
- シナリオ表示・通知・チャート分析といった**裁量の補助ツール**として提供します。
- 改良は v1.1 として事前登録し直し、新しい未接触データ（例：ブローカーの2021年以降）で1回だけ評価します。

## ここから分かったこと（解釈。断定ではなく仮説）

1. **2人の共通点として残った中核セットアップを、機械的なルールにしただけでは、優位性は示せなかった。**
   中核セットアップとは、4時間足の押し目・戻り目を、1時間足の転換で取るものです。
   2人に優位性があるとすれば、その源泉はこのルールの外にあると考えられます。たとえば、節目の選び方、相場環境の読み、見送りの判断といった裁量です。
2. **片方の流儀の条件を足しても良くならなかった。**
   - 100億の条件：日足との一致・反対勢力・MA の収束拡散・分割決済
   - 賢人の条件：節目の支え・節目の外の損切り・目標の節目

   どちらを足して厳選しても、平均はかえって下がりました。前身の 4P-Score と同じ傾向です。
3. **利益の出どころは「週末まで持つ」ことにあり、入り方にはなかった。**
   素朴ベースラインとの差が小さいことと、決済理由の内訳がそれを示しています。
4. **検出力の限界**：1,609回では平均Rの標準誤差が約0.05R です。+0.05R 前後の小さな優位性があっても、この検証では見分けられません（偽陰性の可能性）。
   「優位性がないと証明した」のではなく、「あると言える証拠が得られなかった」という結果です。

## 使い方への影響

- **MT5 EA**：自動売買は既定 OFF のまま。通知とパネルで状況を整理し、最終判断は裁量で行う道具として使ってください。
- **分析スキル `/fx-fusion` とダッシュボード**：同じ規則で相場を読むための補助として使えます。成績の見込みを示すものではありません。
- **次の一歩（v1.1）**
  - 改良案は事前登録してから、新しい未接触データ（ブローカーの2021年以降など）で1回だけ評価します。
  - 今回の結果を見て、同じデータで構成を選び直すことはしません（それをすると、今回の検証の意味がなくなります）。

## 再現方法

```bash
# データ（OANDA 1分足 → H1/M15）は fusion/README.md の「データの準備」を参照
python -m fusion.final_eval --data-dir <H1/M15 のフォルダ> --out <出力フォルダ>
```
